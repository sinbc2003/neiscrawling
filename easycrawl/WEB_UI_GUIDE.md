# EasyCrawl 웹 UI 가이드 🌐

## 🎨 ChatGPT/Claude 스타일의 고급스러운 웹 인터페이스

EasyCrawl 0.2.0부터 **웹 UI**가 추가되었습니다! 이제 브라우저에서 편리하게 크롤러를 관리할 수 있습니다.

---

## ✨ 주요 기능

### 1. **사이드바 히스토리**
- 과거에 만든 모든 크롤러를 사이드바에서 확인
- 검색 기능으로 원하는 크롤러 빠르게 찾기
- 클릭 한 번으로 크롤러 선택

### 2. **버튼 기반 컨트롤**
- ▶️ **실행하기**: 크롤러 시작 (체크포인트에서 재개)
- 🔄 **처음부터 다시**: 체크포인트 무시하고 처음부터 실행
- ⏸️ **일시정지**: 크롤링 일시 중지
- ▶️ **재개하기**: 일시정지한 크롤러 재개
- ⏹️ **중지하기**: 크롤러 완전 중지
- 🗑️ **삭제**: 크롤러 삭제

### 3. **실시간 진행 상황**
- WebSocket을 통한 실시간 업데이트
- 프로그레스 바로 시각적 표시
- 수집된 항목 개수 실시간 확인

### 4. **고급스러운 디자인**
- 다크 모드 기본 제공
- ChatGPT/Claude와 유사한 UI/UX
- 부드러운 애니메이션과 트랜지션
- 반응형 디자인 (모바일/태블릿 지원)

## 🚀 시작하기

### 설치

기존 EasyCrawl이 설치되어 있다면 업데이트하세요:

```bash
pip install --upgrade easycrawl
```

새로 설치하는 경우:

```bash
pip install easycrawl
```

### 실행

```bash
easycrawl-web
```

그러면 다음과 같은 메시지가 표시됩니다:

```
============================================================
🎉 EasyCrawl 웹 UI 시작!
============================================================

🌐 브라우저에서 열기: http://127.0.0.1:5000

💡 팁:
  - Ctrl+C 를 눌러 종료
  - 크롤러 히스토리는 사이드바에서 확인
  - 실행 중인 크롤러는 실시간으로 진행상황 표시

============================================================
```

브라우저가 자동으로 열리고 웹 UI가 표시됩니다!

## 📖 사용 방법

### 1️⃣ 새 크롤러 만들기

1. **"새 크롤러 만들기"** 버튼 클릭
2. 폼 작성:
   - **크롤러 이름**: 영문, 숫자, `_` 사용 (예: `neis_qa_crawler`)
   - **설명**: 이 크롤러가 하는 일 (선택사항)
   - **Claude API 키**: [Claude Console](https://console.anthropic.com/)에서 발급
   - **curl 명령어**: 브라우저 개발자도구에서 복사
   - **출력 형식**: JSONL, JSON, CSV 중 선택
   - **크롤링 속도**: 500ms (기본값)
3. **"AI로 크롤러 생성하기"** 버튼 클릭
4. AI가 분석하고 크롤러 생성! (약 10-30초 소요)

### 2️⃣ 크롤러 실행하기

생성된 크롤러를 클릭하면 상세 화면이 나타납니다:

#### 처음 실행
- **"실행하기"** 버튼 클릭
- 실시간 진행상황이 화면에 표시됨

#### 중간에 끊겼다면
- **"실행하기"** 버튼: 체크포인트부터 이어서 실행
- **"처음부터 다시"** 버튼: 체크포인트 무시하고 처음부터

#### 실행 중 제어
실행 중에는 다음 버튼이 나타납니다:
- **일시정지**: 잠시 멈추기 (나중에 재개 가능)
- **중지하기**: 완전히 중지

#### 일시정지 상태
- **재개하기**: 다시 시작
- **중지하기**: 완전히 중지

### 3️⃣ 크롤러 관리

#### 사이드바에서
- **검색**: 상단 검색창에 크롤러 이름 입력
- **선택**: 크롤러 클릭하면 상세 화면으로

#### 상세 화면에서
- **🔍 코드 보기**: 생성된 Python 코드 확인
- **📥 데이터 다운로드**: 수집된 데이터 파일 다운로드
- **📊 최근 실행 기록**: 과거 실행 기록 확인
- **🗑️ 삭제**: 크롤러 및 모든 기록 삭제

## ⚙️ 고급 설정

### 다른 포트 사용

```bash
easycrawl-web --port 8000
```

### 외부 접속 허용

```bash
easycrawl-web --host 0.0.0.0 --port 5000
```

⚠️ **보안 경고**: 외부 접속 허용 시 방화벽 설정을 확인하세요!

### 디버그 모드

개발자라면 디버그 모드로 실행:

```bash
easycrawl-web --debug
```

### 브라우저 자동 열기 비활성화

```bash
easycrawl-web --no-browser
```

### 데이터베이스 경로 지정

```bash
easycrawl-web --db-path /path/to/easycrawl.db
```

## 🔌 실시간 업데이트 (WebSocket)

웹 UI는 WebSocket을 사용하여 실시간으로 업데이트됩니다:

- **진행 상황**: 2초마다 자동 업데이트
- **완료 알림**: 크롤러 완료 시 즉시 알림
- **연결 상태**: 상단에 연결 상태 표시

연결이 끊어지면 자동으로 재연결을 시도합니다.

## 🐛 문제 해결

### "Connection refused" 오류

서버가 실행 중인지 확인하세요:
```bash
easycrawl-web
```

### 포트가 이미 사용 중

다른 포트로 실행:
```bash
easycrawl-web --port 8000
```

### 브라우저가 자동으로 열리지 않음

수동으로 브라우저를 열고 주소 입력:
```
http://127.0.0.1:5000
```

### 크롤러 실행이 안 됨

1. 크롤러 상세 화면에서 "코드 보기" 클릭
2. `COOKIES` 변수에 실제 쿠키값이 설정되어 있는지 확인
3. 필요하면 파일을 직접 수정:
   ```bash
   nano crawlers/my_crawler/my_crawler.py
   ```

### 데이터베이스 초기화

모든 데이터를 삭제하고 처음부터:
```bash
rm easycrawl.db
easycrawl-web
```

## 🆚 CLI vs 웹 UI

| 기능 | CLI | 웹 UI |
|------|-----|-------|
| 크롤러 생성 | ✅ 대화형 | ✅ 폼 작성 |
| 실행 제어 | ⚠️ 명령어 필요 | ✅ 버튼 클릭 |
| 히스토리 | ❌ 없음 | ✅ 사이드바 |
| 실시간 진행 | ⚠️ 터미널 출력 | ✅ 프로그레스 바 |
| 여러 크롤러 관리 | ❌ 어려움 | ✅ 쉬움 |
| 일시정지/재개 | ❌ 불가능 | ✅ 가능 |
| UI/UX | ⭐⭐ | ⭐⭐⭐⭐⭐ |

### 언제 CLI를 사용할까?
- 빠르게 일회성 크롤러를 만들 때
- 자동화 스크립트에 통합할 때
- GUI 없는 서버 환경

### 언제 웹 UI를 사용할까?
- 여러 크롤러를 관리할 때
- 실행 중 제어가 필요할 때
- 시각적으로 진행 상황을 확인하고 싶을 때
- **일반적인 경우 웹 UI 사용 권장!**

## 🎯 팁과 트릭

### 1. 크롤러 이름 짓기
- 영문 소문자, 숫자, `_` 사용
- 의미있는 이름 사용 (예: `naver_news`, `github_repos`)
- 날짜 포함하면 관리하기 쉬움 (예: `api_scraper_2026`)

### 2. 태그 활용
나중에 추가될 기능이지만, 태그를 미리 생각해두세요:
- 데이터 소스별 (naver, google, github)
- 프로젝트별 (research_project, client_work)
- 주기별 (daily, weekly, once)

### 3. 크롤링 속도 조절
- **500ms (기본)**: 대부분의 경우 안전
- **1000ms (느림)**: 서버 부담 최소, 차단 위험 거의 없음
- **200ms (빠름)**: 빠르지만 차단 위험, 테스트 후 사용

### 4. 데이터 관리
- 정기적으로 `crawlers/` 디렉토리 백업
- 완료된 크롤러는 데이터 다운로드 후 삭제
- 데이터베이스도 주기적으로 백업: `cp easycrawl.db easycrawl.db.backup`

### 5. 여러 크롤러 동시 실행
웹 UI에서 여러 크롤러를 동시에 실행할 수 있습니다!
- 사이드바에서 다른 크롤러 선택
- "실행하기" 클릭
- 각 크롤러의 진행 상황은 독립적으로 관리됨
